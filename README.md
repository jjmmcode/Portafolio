## Getting Started

To run the website locally, you will need a recent Node.js installation and **pnpm**.

```bash
git clone https://github.com/jjmmcode/Portafolio.git
cd Portafolio
pnpm install
pnpm dev
```

Open **http://localhost:3000** in your browser.

> Check `package.json` for the Node.js requirements and available scripts before running the project. If the project uses environment variables, configure them locally rather than committing secrets.

## Deployment

The website is hosted on **Vercel** and connected to this GitHub repository. Changes merged into the configured production branch can trigger new deployments, depending on the project's Vercel settings.
