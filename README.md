# 🌟 Portafolio de Joel Medina

Bienvenido/a a mi portafolio de desarrollador web y backend. Este proyecto tiene como finalidad mostrar mis habilidades, proyectos y trayectoria de forma clara, profesional y visualmente atractiva.

> ✨ Basado en la plantilla de [@mouredev](https://github.com/mouredev) - todos los créditos a su autor.

---

## 📁 Contenido del repositorio

* 'data.json' : archivo donde configuro toda la información visible del portafolio (experiencia, formación, proyectos, etc).
* 'portafolio.py' : archivo principal donde se define la estructura del sitio usando Reflex.
* 'theme.py' : configuración de estilos visuales y colores.
* 'vercel.json' : configuración para despliegue automático en Vercel.
* 'build.sh' : script para generación del build.
